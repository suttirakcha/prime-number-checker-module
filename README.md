## A Prime Number Checker

A package number checking if the number is a prime number or not

```js
const primeNumberChecker = require("./index");

console.log(primeNumberChecker.isPrime(2)); // true
console.log(primeNumberChecker.isPrime(3)); // true
console.log(primeNumberChecker.isPrime(5)); // true
console.log(primeNumberChecker.isPrime(8)); // false
```
